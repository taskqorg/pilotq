## Implementation boundaries

Originals and model input are temporary; audit retains identity and read outcome. The scoped reader accepts only the current run's attachment index and character offset, rechecks admission and fencing, and never accepts a filesystem path. It reads UTF-8 originals; other document types retain their preview or exact unsupported reason. Existing private routes and grant boundaries remain unchanged.

Album aggregation and update dispositions share the ingress transaction. Membership is bound to sender, route and conversation generation. Prior file snapshots remain in audit. The first member owns the request and reply destination. Already-started work is not changed by a late member. Photo/video and audio albums use the same aggregation boundary; audio transcripts are joined in file order before one journal transcript is committed.

Audio splitting operates on decoded mono PCM, honors WAV chunk boundaries and retains the original recognition deadline. Failure in any segment prevents a partial transcript from being reported as complete. Recognition accuracy at segment boundaries is unqualified until the real-model run.
